# Pièges du projet

Mémoire collective des pièges découverts **sur ce projet** : datasets, champs, valeurs,
maquette, comportements confirmés par le client. `docs/PROMPT_DEV_ECRAN.md` fait lire ce
fichier avant chaque écran.

Ajouter un piège dès qu'il est découvert, avant de l'oublier. Un piège valable pour tous les
projets va plutôt dans la section « Pièges génériques » de `docs/PROMPT_DEV_ECRAN.md` (et dans
le starter kit).

## Format

```markdown
- [x] **<dataset ou écran concerné>** — <le piège en une phrase>.
      Comment on l'a vu : <symptôme, ex. valeur qui disparaît sans erreur>.
      Ce qu'on fait : <la règle ou le contournement appliqué, fichier/composant concerné>.
      (<date>, <source : curl, réponse client du JJ/MM, maquette…>)
```

Un piège en attente côté données ou client : `- [ ]` + 🔲 TODO, avec ce qu'il faudra changer
quand la réponse arrivera.
